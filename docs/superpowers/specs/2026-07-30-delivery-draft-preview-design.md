# 成果交付草稿预览设计

## 目标

成果交付页列出已发起创作任务项目的所有实际生成成果，包括草稿；用户可为草稿创建可下载快照。草稿快照仅用于预览和审计，不会完成交付工作流或推动选题库生命周期。

## 资源范围

资源选项从项目的已生成数据中取得，而不是从当前锁定指针取得：

- Brief：全部蓝图版本。
- 人物关系：全部存在人物的批次，每批次仅显示一次。
- 分集大纲：全部存在分集的批次，每批次仅显示一次。
- Beats：全部单集版本。
- 场次剧本：全部单集版本。

项目必须至少存在一个创作生成资源，空项目不会出现在选项中。项目访问权限过滤保持不变。

## 快照与正式交付

创建快照时记录资源当前状态。`locked`、`brief_locked` 和 `approved` 资源为正式交付；其行为维持原状，包括交付任务完成、阶段导出记录和审计交付。

`draft` 资源为预览快照：

- 可生成 Markdown、TXT 或 JSON 文件并下载。
- 记录创建人、内容指纹和资源状态。
- 不要求存在交付工作流任务。
- 不记录 Beats 或场次剧本的阶段导出。
- 不完成交付工作流任务，不能影响 `script_exported` 等选题库状态。

## 页面

将“已完成版本”改为“可预览成果”，并在每个选项中显示状态标签，例如“草稿”或“已锁定”。历史列表显示快照属性，草稿记录标为“预览快照”，正式记录标为“正式交付”。

## 验证

- 草稿 Brief、人物关系批次、分集大纲批次、Beats 和场次剧本都出现在资源选项中。
- 草稿可创建并下载快照。
- 草稿快照不创建阶段导出记录，也不完成交付工作流任务。
- 已锁定资源继续创建正式交付，保留现有生命周期推进行为。
- 页面文本和选项标签反映草稿/正式状态。
