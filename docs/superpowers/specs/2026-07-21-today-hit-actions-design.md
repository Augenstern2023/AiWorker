# 今日爆款状态操作设计

## 目标

今日爆款列表的操作按钮必须与选题状态一致，避免已采纳剧目仍出现“不跟进”等冲突操作。

## 状态规则

| 状态 | 可见操作 |
| --- | --- |
| `pending_review` | 采纳、拆解、不跟进 |
| `adopted` | 拆解 |
| `rejected` | 重新采纳 |
| `archived` | 不在今日爆款候选操作中提供状态变更 |

“重新采纳”继续调用现有选题状态更新接口，将状态更新为 `adopted`。本次只调整今日爆款列表，不改变选题库的归档和创作项目操作。

## 交互与验收

- 已采纳行不显示“采纳”和“不跟进”。
- 不跟进行不重复显示“不跟进”，只显示“重新采纳”。
- 待评估行保持现有三个操作。
- 状态更新后按钮立即随本地记录状态切换，不要求手动刷新页面。
