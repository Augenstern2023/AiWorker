# 项目负责人注册与多账号分配设计

## 背景

项目负责人需要可在注册时申请，也需要由系统管理员在用户管理中直接分配。该角色不再受全局唯一限制；系统管理员仍保留至少一个启用账号的保护。

## 设计

注册角色白名单加入 `project_owner`，注册页新增“项目负责人”复选项。注册申请继续创建为停用账号，管理员激活后其已申请角色才可生效。

管理员用户管理沿用现有的新建和编辑角色多选控件，移除项目负责人只能经专用接任操作变更的服务端限制。系统管理员角色不加入注册白名单，且既有“至少保留一个启用的系统管理员”约束不变。

## 错误处理

注册接口仍拒绝任何不在白名单内的角色。项目负责人角色被停用或删除时，注册接口返回“所选角色不可用”。

## 验证

PostgreSQL 集成测试验证：项目负责人可通过注册申请保存为停用账号；管理员可通过用户管理创建并编辑多个项目负责人；注册申请仍拒绝系统管理员；最后一个启用的系统管理员仍受保护。
