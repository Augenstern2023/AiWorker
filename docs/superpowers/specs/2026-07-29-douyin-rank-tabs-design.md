# 抖音榜单与热榜分栏设计

## 目标

今日榜单中的抖音数据按抖音原始榜单分为“榜单”和“热榜”两个独立页签，默认展示“榜单”。排名、上榜、下榜和变动统计只在各自页签内计算与展示，不再将两个榜单混排。

## 数据与分组

抖音快照中的 `tab` 是原始榜单标识。后端按 `tab` 将当前期和上一期记录拆为两个排名表，并分别复用现有比较逻辑。每个排名表保留完整的 `summary`、`current_entries`、`new_entries`、`dropped_entries`、`rank_up`、`rank_down` 和列定义。

`热榜`不补齐、不截断，也不重新编号。当前采集到的 7 条热榜记录原样展示；其数量由快照决定。`榜单`和`热榜`中的同名剧目互不影响排名变化。

## 界面

抖音页面使用与红果相同的榜单切换模式：在平台选择下方展示“榜单”“热榜”按钮，默认选择“榜单”。选择页签后，顶部六个统计卡、表格数据及表格内的“当前榜单 / 新上榜 / 下榜 / 排名上升 / 排名下降”子页签都切换到该榜单的数据。

切换状态写入 `#/today-rank/dy/<榜单名>` 路由，刷新或直达链接后仍恢复对应页签。红果现有路由和交互保持不变。

## 错误处理与测试

缺少某一榜单时仍展示其页签和空状态，不把另一榜单的记录混入。后端测试验证两个页签分别统计且热榜 7 条不发生增删；前端模板测试验证抖音路由、默认“榜单”和两个切换按钮存在。
