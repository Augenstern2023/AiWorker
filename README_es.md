## 📖 Introducción del Proyecto

Una potente **herramienta de Empleado Digital AI** que soporta rastreo de contenido de Douyin, gestión de comentarios, exportación de datos y flujo de trabajo automatizado.

### 🔧 Principios Técnicos

- **Tecnología Central**: Basado en el framework de automatización de navegador [Playwright](https://playwright.dev/) y modo CDP
- **Flujo de Trabajo Automatizado**: Contents → Comments → Exportación Excel → Carga Automática, completamente automatizado

## ✨ Características
| Módulo de Función | Descripción |
| ----------------- | ----------- |
| Rastreo de Contenido | Búsqueda por palabras clave, detalles de video, página de creador |
| Rastreo de Comentarios | Comentarios primarios, comentarios secundarios |
| Auto托管 | Auto completo: Rastreo → Exportación → Carga |
| Multi-proyecto | Gestionar múltiples proyectos con palabras clave separadas |
| Exportación de Datos | Soporta formatos JSON, Excel |
| Carga Automática | Cargar automáticamente a la interfaz especificada después de exportar |

## 📋 Prerrequisitos

### 🚀 Instalación de uv (Recomendado)

Antes de proceder con los siguientes pasos, por favor asegúrese de que uv esté instalado en su computadora:

- **Guía de Instalación**: [Guía Oficial de Instalación de uv](https://docs.astral.sh/uv/getting-started/installation)
- **Verificar Instalación**: Ingrese el comando `uv --version` en la terminal. Si el número de versión se muestra normalmente, la instalación fue exitosa
- **Razón de Recomendación**: uv es actualmente la herramienta de gestión de paquetes Python más poderosa, con velocidad rápida y resolución de dependencias precisa

### 🟢 Instalación de Node.js

El proyecto depende de Node.js, por favor descargue e instale desde el sitio web oficial:

- **Enlace de Descarga**: https://nodejs.org/en/download/
- **Requisito de Versión**: >= 16.0.0

### 📦 Instalación de Paquetes Python

```shell
# Entrar al directorio del proyecto
cd MediaCrawler

# Usar el comando uv sync para asegurar la consistencia de la versión de python y paquetes de dependencias relacionados
uv sync --locked --group dev
```

Si un sistema externo debe recibir un archivo de requirements, expórtelo bajo demanda en lugar de usarlo como entrada de instalación del proyecto:

```shell
uv export --locked --no-dev --format requirements-txt > requirements.generated.txt
```

### 🌐 Instalación de Controlador de Navegador

```shell
# Instalar controlador de navegador
uv run playwright install
```

### ✅ Verificar la instalación

```shell
uv run main.py --help
```

## 🖥️ Interfaz GUI

AiWorker proporciona tres métodos de inicio:

| Método de Inicio | Archivo Batch | Descripción |
|-----------------|---------------|-------------|
| GUI Principal | `启动程序.bat` | Ejecuta `GUI.py`, GUI de escritorio completo |
| GUI Web | `启动Web程序.bat` | Ejecuta `WebGUI.py`, acceso desde navegador |

```shell
# Usuarios de Windows: haga doble clic en los archivos .bat anteriores
# O ejecute manualmente:
python GUI.py      # GUI de escritorio
python WebGUI.py   # Interfaz web (predeterminado http://localhost:8080)
```

> Nota: WebGUI depende de FastAPI y uvicorn. Asegúrese de haber ejecutado `uv sync --locked --group dev` para instalar dependencias.
