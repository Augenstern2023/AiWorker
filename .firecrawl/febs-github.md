## 系统简介

[Permalink: 系统简介](https://github.com/lxguidu/FEBS#%E7%B3%BB%E7%BB%9F%E7%AE%80%E4%BB%8B)

[FEBS](https://gitee.com/github-16661027/project) 是一个简单高效的后台权限管理系统。项目基础框架采用全新的Java Web开发框架 —— Spring Boot，消除了繁杂的XML配置，使得二次开发更为简单；数据访问层采用Mybatis，同时引入了通用Mapper和PageHelper插件，可快速高效的对单表进行增删改查操作，消除了大量传统XML配置SQL的代码；安全框架采用时下流行的Apache Shiro，可实现对按钮级别的权限控制；前端页面使用Bootstrap构建，主题风格为时下Google最新设计语言Material Design，并提供多套配色以供选择。FEBS意指：Fast，Easy use，Beautiful和Safe🙄。

## 功能模块

[Permalink: 功能模块](https://github.com/lxguidu/FEBS#%E5%8A%9F%E8%83%BD%E6%A8%A1%E5%9D%97)

系统功能模块组成如下所示：

```
├─系统管理
│  ├─字典管理
│  ├─用户管理
│  ├─菜单管理
│  ├─角色管理
│  └─部门管理
├─系统监控
│  ├─在线用户
│  └─系统日志
├─任务调度
│  ├─定时任务
│  └─调度日志
└─网络资源
    ├─One一个
    │  ├─散文
    │  ├─绘画
    │  └─语文
    ├─天气查询
    ├─影视资讯
    │  ├─即将上映
    │  └─正在热映
    └─每日一文
```

## 技术选型

[Permalink: 技术选型](https://github.com/lxguidu/FEBS#%E6%8A%80%E6%9C%AF%E9%80%89%E5%9E%8B)

### 后端

[Permalink: 后端](https://github.com/lxguidu/FEBS#%E5%90%8E%E7%AB%AF)

- 基础框架：Spring Boot

- 持久层框架：Mybatis

- 安全框架：Apache Shiro

- 摸板引擎：Thymeleaf

- 数据库连接池：阿里巴巴Druid

- 缓存框架：Ehcache

- 日志打印：logback

- 其他：fastjson，poi，javacsv，quartz等。


### 前端

[Permalink: 前端](https://github.com/lxguidu/FEBS#%E5%89%8D%E7%AB%AF)

- 基础框架：Bootstrap

- JavaScirpy框架：jQuery

- 消息组件：Bootstrap notify

- 提示框插件：SweetAlert2

- 树形插件：jsTree

- 树形表格插件：jqTreeGrid

- 表格插件：BootstrapTable

- 表单校验插件：jQuery-validate

- 多选下拉框插件：multiple-select

- 图表插件：Highcharts


### 开发环境

[Permalink: 开发环境](https://github.com/lxguidu/FEBS#%E5%BC%80%E5%8F%91%E7%8E%AF%E5%A2%83)

- 语言：Java

- IDE：Eclipse Oxygen

- 依赖管理：Maven

- 版本管理：SVN，git
