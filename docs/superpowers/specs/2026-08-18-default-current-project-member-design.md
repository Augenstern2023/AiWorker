# 创建项目时默认选择当前用户

## 目标

“创建项目及任务”弹窗加载候选用户后，默认选择当前登录用户。默认选择依据用户 ID，不新增、不替换、不修改任何后台角色；用户仍可手动取消。

## 设计

候选接口在每条用户记录上返回 `is_current_user`。该值仅由请求主体的 `principal.user_id` 与候选 `user_id` 比较得出，不写入数据库。前端合并检查两个现有候选列表，找到第一个标记为当前用户的记录后，只在其所在列表中填入该用户 ID，避免同一用户被默认重复选择。

## 验证

API 测试验证只有请求账户带有 `is_current_user: true`；浏览器行为测试验证打开弹窗后当前用户已默认选中、其他用户未选中，且初始选择仍是普通数组，可由界面取消。
