# 今日爆款榜单来源设计

## 目标

今日爆款在平台之外增加榜单来源维度。抖音可切换“榜单”“热榜”，默认“榜单”；红果可切换“全部”“真人剧”“漫剧”“AI剧”，默认“全部”。所选来源同时决定 Top10 的候选范围和页面展示范围，刷新后恢复最近选择。

## 数据与接口

`creative_topics` 增加 `rank_source` 字段，保存候选所属的一级榜单来源。`rank_type` 继续保存具体榜单名称，保持现有数据含义。榜单记录转换为候选时按平台归一化来源：抖音取 `tab`；红果取 `board_section`。

`POST /api/creative/topics/generate` 增加 `rank_source`，仅从对应来源的今日榜单 section 生成候选。`GET /api/creative/topics` 增加同名筛选参数，确保同一天其他来源的待采纳候选不会混入当前列表。缺失来源参数时使用平台默认值，兼容现有调用。

## 界面与状态

平台选择器下方显示一组紧凑的来源按钮。切换平台时重置为该平台默认来源；切换来源时立即重新生成对应 Top10。平台和来源分别写入 localStorage。

表格将“平台”列改为“榜单来源”，显示 `rank_source`；空值按 `rank_type` 兼容推导。加载、空状态和错误提示复用现有区域，不新增弹窗。

## 测试与兼容性

服务测试覆盖抖音与红果 section 取数、来源写入和无效来源；API/仓储测试覆盖来源筛选；前端源码测试覆盖按钮、请求参数、缓存键与表头。数据库启动时按现有轻量迁移模式补列，旧记录保持可读。
